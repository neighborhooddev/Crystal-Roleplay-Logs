v0.1 — v3.0 In Development SA-MP Roleplay Project Foundation First

Crystal Roleplay Development Logs are maintained as a chronological record of the project's technical and structural evolution. Each release represents a development stage rather than simply a collection of gameplay features.


The project follows a foundation-first approach: Foundation → System Dasar → Core Mechanic → Integration → Command → Gameplay.

Version 3.0

Player Runtime Metadata

A new runtime metadata layer for the next generation of CRP systems.

Development Focus

v3.0 introduces a structured runtime metadata layer. The system is designed to provide future CRP systems with additional runtime context while remaining independent from account, character, database, command, and gameplay systems.

Developer Note

Crystal Roleplay continues to be developed with a foundation-first philosophy. v3.0 does not attempt to rush into gameplay features. Instead, it strengthens the runtime architecture that future systems will rely on.
